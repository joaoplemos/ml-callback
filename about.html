Deals Scanner

Deals Scanner is a personal tool that uses the Mercado Libre API to find product deals and promotions and share them with an audience through affiliate links.

How it works

  1. The application queries the Mercado Libre API to read public listing data: product titles, prices, discounts and active promotions.
  2. It identifies the best deals and opportunities.
  3. The owner manually reviews and approves each deal.
  4. Approved deals are shared in messaging groups using the owner's affiliate link, in order to earn affiliate commissions.

Data usage

  • The application only reads public listing data.
  • It does not collect, store or sell personal data from any user.
  • It is used by a single owner, with his own Mercado Libre account.
